🚀 Complete Content Management Guide

Learn where to edit every section of the Rising Dot Agency website. This guide covers all 13 homepage sections and 5 service pages.

📌 Important: Most content is stored in local files for optimal performance. Only blogs and select CMS sections use the database.

⚡ Quick Start Guide

How to Edit Hero Section Text

Method 1: Via Admin Dashboard (CMS)

  1. Go to /admin/pages/home
  2. Find "Hero Section" card
  3. Click "Edit" button
  4. Modify the JSON content
  5. Click "Save"
  6. Wait 30 seconds for ISR revalidation
  7. Refresh homepage to see changes

Method 2: Edit Code Directly

  1. Open components/sections/CleanHero.tsx
  2. Find the text you want to change (lines 67-130)
  3. Edit and save
  4. Commit: git commit -am "Update hero text"
  5. Push: git push origin main
  6. Vercel auto-deploys

How to Add Portfolio Project

  1. Prepare image: 1470x980px, < 500KB
  2. Upload to /public/media/homepage/portfolio/
  3. Open components/sections/PortfolioGallery.tsx
  4. Add to galleryData array:
TypeScript 
{
  id: 10,
  src: '/media/homepage/portfolio/project-name.jpg',
  alt: 'Project Description',
  title: 'Project Name',
  span: 'col-span-1'
}
  1. Save, commit, and push

🔧 Troubleshooting

CMS changes not appearing

Solutions:

  1. Wait 30 seconds for ISR revalidation
  2. Hard refresh: Ctrl+Shift+R (Win) or Cmd+Shift+R (Mac)
  3. Clear browser cache or try incognito mode
  4. Check JSON syntax with a validator

Images not displaying

Check:

  1. File path starts with /
  2. File name is case-sensitive
  3. File format is supported (JPG, PNG, WebP, SVG)
  4. Image is actually uploaded to correct folder
